# لوحة متابعة برامج الخطة التشغيلية

موقع مستقل بلا تسجيل دخول: صفحة واحدة (`index.html`) وواجهة بيانات (`api/data.js`) تعمل على Vercel مع قاعدة بيانات Neon.

- **النشر:** كل تحديث يُرفع إلى هذا المستودع يُنشر تلقائيًا على Vercel.
- **قاعدة البيانات:** تُربط من Vercel → Storage → Neon. تُنشأ الجداول تلقائيًا عند أول تشغيل، ولا يلزم تشغيل أي سكربت.
- **النسخ الاحتياطي:** كل تعديل أو حذف لبرنامج يُحفظ تلقائيًا في جدول `programs_history` داخل قاعدة البيانات، لاسترجاع ما حُذف بالخطأ.
- **الأمان:** رابط الاتصال بقاعدة البيانات يبقى سريًا في إعدادات Vercel، ولا يظهر داخل الصفحة. والخادم يتحقق من صحة كل بيانات تُرسل إليه.

## ملف الشواهد

صفحة `/hanan-alharbi`، ورابطها السابق `/evidence` ما زال يعمل (الواجهة `evidence/index.html` والبيانات `api/evidence.js` و`lib/ev-core.js`): ملف شواهد الأداء الوظيفي لمديرة المدرسة، بقاعدة البيانات نفسها. تُنشأ جداولها (`ev_links` و`ev_settings`) تلقائيًا، وكل تعديل أو حذف لرابط يُحفظ في `ev_links_history`. رابط العرض `/evidence?view=1` يخفي أزرار التعديل فقط، وليس وسيلة حماية.
