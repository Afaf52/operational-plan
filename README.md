# لوحة متابعة برامج الخطة التشغيلية

موقع مستقل بلا تسجيل دخول: صفحة واحدة (`index.html`) وواجهة بيانات (`api/data.js`) تعمل على Vercel مع قاعدة بيانات Neon.

- **النشر:** كل تحديث يُرفع إلى هذا المستودع يُنشر تلقائيًا على Vercel.
- **قاعدة البيانات:** تُربط من Vercel → Storage → Neon. تُنشأ الجداول تلقائيًا عند أول تشغيل، ولا يلزم تشغيل أي سكربت.
- **النسخ الاحتياطي:** كل تعديل أو حذف لبرنامج يُحفظ تلقائيًا في جدول `programs_history` داخل قاعدة البيانات، لاسترجاع ما حُذف بالخطأ.
- **الأمان:** رابط الاتصال بقاعدة البيانات يبقى سريًا في إعدادات Vercel، ولا يظهر داخل الصفحة. والخادم يتحقق من صحة كل بيانات تُرسل إليه.

## ملف الشواهد

صفحة `/hanan-alharbi`، ورابطها السابق `/evidence` ما زال يعمل (الواجهة `evidence/index.html` والبيانات `api/evidence.js` و`lib/ev-core.js`): ملف شواهد الأداء الوظيفي لمديرة المدرسة، بقاعدة البيانات نفسها. تُنشأ جداولها (`ev_links` و`ev_settings`) تلقائيًا، وكل تعديل أو حذف لرابط يُحفظ في `ev_links_history`. لكل عام من 1447 إلى 1450 شواهده (الحقل `year` داخل `data`، والروابط التي بلا عام تُعد من 1448). رابط العرض `/hanan-alharbi?view=1&year=1448` يخفي أزرار التعديل فقط، وليس وسيلة حماية.

## لوحة التكريم

صفحة `/takreem` (الواجهة `takreem/index.html` والبيانات `api/awards.js` و`lib/aw-core.js`): أنشطة القدرات والتحصيلي وستيب، وتحليلات من 1447 إلى 1450، ومراكز المعلمات وشاراتهن وشهادات الشكر، بقاعدة البيانات نفسها. تُنشأ جداولها (`aw_activities` و`aw_settings`) تلقائيًا، وكل تعديل أو حذف لنشاط يُحفظ في `aw_activities_history`. رابط العرض `/takreem?view=1#awards` يخفي أزرار التعديل فقط، وليس وسيلة حماية. ورابط `/takreem?demo=1#awards` يعرض أمثلة غير محفوظة ما دامت اللوحة فارغة.
